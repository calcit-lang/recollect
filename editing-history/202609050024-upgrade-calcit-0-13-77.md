# Calcit 0.13.77 upgrade / 升级 Calcit 0.13.77

## 中文

- 将 Recollect 的 `deps.cirru :calcit-version` 与 `@calcit/procs` 从 0.13.76 同步升级到精确版本 0.13.77。
- 保持 Recollect 的 diff/patch 实现与语义不变；将 Respo 依赖链更新到包含 0.13.77 兼容修复的正式版本，Snapshot 仅包含所需的示例样式迁移。
- 将示例样式的数值 `:padding 8` 改为 CSS 等价字符串 `:padding |8px`，满足 0.13.77 对 `ui/row` 的 `map<tag,string>` 参数检查。
- 使用正式 0.13.77 工具链验证 native、JavaScript 与 WASM 路径；将 checkout、Node setup 与 Calcit setup Actions 固定到明确正式版本。
- 使用 Respo 0.16.91、Respo UI 0.7.16、Reel 0.6.13、Respo Markdown 0.4.31 与 Respo Value 0.5.4；这些不可变版本已解除原 calcit#670 阻塞。

## English

- Upgrade Recollect's `deps.cirru :calcit-version` and `@calcit/procs` together from 0.13.76 to the exact 0.13.77 release.
- Keep Recollect's diff/patch implementation and semantics unchanged; update the Respo dependency chain to immutable releases containing the 0.13.77 compatibility fixes, while limiting the Snapshot to the required demo-style migration.
- Change the demo style from numeric `:padding 8` to the CSS-equivalent string `:padding |8px`, satisfying 0.13.77's `map<tag,string>` check for `ui/row`.
- Validate native, JavaScript, and WASM paths with the released 0.13.77 toolchain; pin checkout, Node setup, and Calcit setup Actions to explicit released versions.
- Use Respo 0.16.91, Respo UI 0.7.16, Reel 0.6.13, Respo Markdown 0.4.31, and Respo Value 0.5.4; these immutable releases resolve the former calcit#670 blocker.
