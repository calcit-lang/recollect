# Calcit 0.13.77 upgrade / 升级 Calcit 0.13.77

## 中文

- 将 Recollect 的 `deps.cirru :calcit-version` 与 `@calcit/procs` 从 0.13.76 同步升级到精确版本 0.13.77。
- 保持 Recollect 的 diff/patch 实现与语义、Respo 依赖 revisions 及 CI workflow 不变；Snapshot 仅包含所需的示例样式迁移。
- 将示例样式的数值 `:padding 8` 改为 CSS 等价字符串 `:padding |8px`，满足 0.13.77 对 `ui/row` 的 `map<tag,string>` 参数检查。
- 使用从 0.13.77 crate 源码构建的目标版本 CLI 验证 native、JavaScript 与 WASM 路径；Linux GitHub Actions 继续作为官方 release 资产的发布级证据。
- Calcit 0.13.77 在 stable Rust 上的 `cargo install` 回归由 calcit#660 独立跟踪，不在下游仓库加入 workaround；Respo 0.16.90 的 `decorate-defcomp` callback 诊断由 calcit#670 跟踪并阻塞本次完整验证。

## English

- Upgrade Recollect's `deps.cirru :calcit-version` and `@calcit/procs` together from 0.13.76 to the exact 0.13.77 release.
- Keep Recollect's diff/patch implementation and semantics, Respo dependency revisions, and CI workflow unchanged; the Snapshot contains only the required demo-style migration.
- Change the demo style from numeric `:padding 8` to the CSS-equivalent string `:padding |8px`, satisfying 0.13.77's `map<tag,string>` check for `ui/row`.
- Validate native, JavaScript, and WASM paths with a target-version CLI built from the 0.13.77 crate source; Linux GitHub Actions remains the release-grade evidence for the official release assets.
- Track the stable-Rust `cargo install` regression in calcit#660 without adding a downstream workaround; calcit#670 tracks the Respo 0.16.90 `decorate-defcomp` callback diagnostic that blocks complete validation here.
