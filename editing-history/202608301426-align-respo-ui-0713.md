# Respo dependency alignment / 对齐 Respo 依赖链

## 中文

- 将 Reel 升级到 0.6.10、respo-markdown 升级到 0.4.28、Respo UI 升级到 0.7.13。
- 这些中间模块已经完成 Calcit 0.13.64 回归并发布，因此 Recollect 可以使用同一条 Respo UI 版本链。
- 通过 strict Caps 守门，要求解析结果不再包含版本选择 warning，并保持 validated patch、diff/patch 与 projection API 不变。

## English

- Upgrade Reel to 0.6.10, respo-markdown to 0.4.28, and Respo UI to 0.7.13.
- These intermediate modules have completed Calcit 0.13.64 regression coverage and have been released, so Recollect can use one aligned Respo UI dependency chain.
- Enforce strict Caps with no version-selection warning while preserving validated patch, diff/patch, and projection APIs.
