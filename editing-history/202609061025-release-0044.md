# Recollect 0.0.44 / Recollect 0.0.44

## English

- Restore the modules declared by the default Snapshot entry to runtime dependencies.
- Recollect consumers load the module's default entry metadata, so moving Respo, Respo UI, Respo Value, and JS FFI to development-only dependencies caused clean consumers to miss required module snapshots.
- Keep the published Respo 0.16.95 and Respo Value 0.5.5 chain while restoring a complete transitive graph.

## 中文

- 将 default Snapshot entry 声明的模块恢复为运行时依赖。
- Recollect 消费者会读取模块的 default entry 元数据，因此把 Respo、Respo UI、Respo Value 与 JS FFI 移到仅开发依赖会导致干净消费者缺少必要的模块 Snapshot。
- 保持已发布的 Respo 0.16.95 与 Respo Value 0.5.5 依赖链，同时恢复完整的传递依赖图。
