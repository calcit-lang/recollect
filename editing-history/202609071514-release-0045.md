# Release 0.0.45 / 发布 0.0.45

Release time / 发布时间: 2026-09-07 15:14 UTC

## 中文

- 发布 Recollect 0.0.45。
- 新增确定性的 visited-node 与 emitted-operation 构造工作预算，以及不携带半批 patch 的具名原子结果。
- 保持原有 `diff-twig` API 与无限预算热路径兼容，并记录 exact-limit、调用隔离、native/JS 和 patch roundtrip 验证。

## English

- Release Recollect 0.0.45.
- Add deterministic visited-node and emitted-operation-construction budgets with a nominal atomic result that never exposes a partial patch batch.
- Preserve the existing `diff-twig` API and unlimited hot path, with exact-limit, call-isolation, native/JS, and patch-roundtrip validation.
