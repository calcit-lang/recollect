# Calcit 0.13.64 upgrade / 升级 Calcit 0.13.64

## 中文

- 将 Recollect 的 Calcit CLI 与 `@calcit/procs` 从 0.13.63 同步升级到 0.13.64。
- 保持 `Respo/respo-ui.calcit` 0.7.12：`reel` 与 `respo-markdown` 仍固定该版本，先避免 strict Caps 出现版本选择 warning。
- 保持 validated patch、diff/patch 与 projection API 不变，并通过 native、JS、WASM 与 Vite 回归验证。

## English

- Upgrade the Recollect Calcit CLI and `@calcit/procs` together from 0.13.63 to 0.13.64.
- Keep `Respo/respo-ui.calcit` at 0.7.12 because `reel` and `respo-markdown` still pin that version, avoiding a strict Caps version-selection warning until those intermediate modules are released.
- Keep validated patch, diff/patch, and projection APIs unchanged, with native, JS, WASM, and Vite regression coverage.
