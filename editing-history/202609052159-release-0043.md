# Release 0.0.43 / 发布 0.0.43

Release preparation time / 发布准备时间: 2026-09-05 21:59 UTC

## 中文

- 准备发布 Recollect 0.0.43，并对齐 Respo 0.16.95、Respo UI 0.7.19 与 Respo Value 0.5.5。
- 将仅供仓库 demo 使用的 Respo 依赖迁移到 `:dev-dependencies`，避免 Recollect 消费者继承无关的 UI 依赖图。
- 移除未使用的 Reel 与 Respo Markdown 直接依赖，并增加明确的 JS FFI demo 依赖。

## English

- Prepare Recollect 0.0.43 with Respo 0.16.95, Respo UI 0.7.19, and Respo Value 0.5.5.
- Move demo-only Respo packages to `:dev-dependencies` so Recollect consumers no longer inherit an unrelated UI dependency graph.
- Remove unused direct Reel and Respo Markdown dependencies, and declare the demo's JS FFI dependency explicitly.
