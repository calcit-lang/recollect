# Release 0.0.39 / 发布 0.0.39

## 中文

- 发布 Recollect 0.0.39，要求 Calcit CLI 与 `@calcit/procs` 0.13.64。
- 保持 validated patch、diff/patch、projection API 与现有 strict quality baseline 不变。
- 继续保持 Respo UI 0.7.12，直到 `reel` 与 `respo-markdown` 的中间依赖完成一致升级。

## English

- Release Recollect 0.0.39 with Calcit CLI and `@calcit/procs` 0.13.64 required.
- Keep validated patch, diff/patch, projection APIs, and the existing strict quality baseline unchanged.
- Keep Respo UI at 0.7.12 until the intermediate `reel` and `respo-markdown` dependencies are upgraded coherently.
