# Budgeted diff traversal

- Add `diff-twig-budgeted` with independent visited-node and emitted-operation limits.
- Return an atomic nominal outcome: complete changes with work statistics, or a budget-exceeded reason without partial changes.
- Keep the existing `diff-twig` implementation and result shape unchanged.
- Cover exact limits, traversal-heavy changes, nested paths, call isolation, patch roundtrips, and the JavaScript runtime.
- Validate with Calcit 0.13.77 (the version pinned by this release line), the static quality baseline, native and JavaScript tests, the existing WASM regression suite, and a Node 24 Vite build.
