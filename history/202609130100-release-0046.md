# Release 0.0.46 / 发布 0.0.46

- Upgrade the project toolchain to Calcit and `@calcit/procs` 0.14.11 with the current typed Respo dependency chain.
- Fix dynamic set-difference direction so budgeted diffs match legacy diffs and set patches round-trip correctly.
- Restore typed list and Struct patch association, and make `PatchBatch .apply-to` use a valid generic trait contract.
- Repair memo cache frame bookkeeping and remove the remaining runtime dynamic-method lookup.
- Add strict public-API, example, and per-definition quality gates; the reviewed baseline keeps the open twig/diff/patch boundaries explicit while preventing new type debt.
- Keep the experimental WASM regression visible but non-blocking until the backend produces deterministic valid modules across platforms.
- 将项目工具链升级到 Calcit 与 `@calcit/procs` 0.14.11，并对齐当前强类型 Respo 依赖链。
- 修正动态集合差集方向，确保预算 diff 与原实现一致，并恢复集合 patch 往返语义。
- 恢复 List 与 Struct 的类型化 patch 写入，使 `PatchBatch .apply-to` 使用合法的泛型 trait 契约。
- 修复 memo cache frame 记账及残留的运行时动态方法分派。
- 增加严格的公共 API、示例及逐定义质量门禁；经审阅的基线显式保留 twig/diff/patch 的开放数据边界，并阻止新增类型债务。
- 保留实验性 WASM 回归检查及其可见结果，但在后端能跨平台稳定生成有效模块前不作为发布阻塞门禁。
